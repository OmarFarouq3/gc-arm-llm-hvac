# Data

Raw and processed data are git-ignored. Each member downloads the data locally.

## LBNL chiller plant dataset

1. Go to https://faultdetection.lbl.gov/data
2. Open **Chiller plant** ("7 faults at various severity levels in a chiller plant", simulated, 1 year).
3. Download the files into `data/raw/chiller_plant/`.
4. Record in `dataset_notes.md` (Member A): file names, rows/columns, sampling interval,
   date range, sensor list with units, where fault labels are stored, the 7 faults and severities.

Cite: J. Granderson et al., "A labeled dataset for building HVAC systems operating in faulted
and fault-free states," Scientific Data, vol. 10, 342, 2023. doi:10.1038/s41597-023-02197-w
