# Dataset notes: LBNL simulated chiller plant

Status: confirmed against the official documentation `LBNL_FDD_Data_Sets_Chiller_Plant.pdf` (LBNL/PNNL, 1 Sept 2022).

## Source

Lawrence Berkeley National Laboratory (LBNL) Fault Detection and Diagnostics Data Sets, chiller plant.
Download: https://faultdetection.lbl.gov/dataset/simulated-chiller-plant/ ("Download all", 1.14 GB zip).
Cite (dataset): Lawrence Berkeley National Laboratory, LBNL FDD Data Sets. DOI: 10.25984/1881324
Cite (paper): J. Granderson et al., "A labeled dataset for building HVAC systems operating in faulted and
fault-free states," Scientific Data, vol. 10, 342, 2023. doi:10.1038/s41597-023-02197-w

Generated by simulation (EnergyPlus + Modelica) of a chiller plant serving a 12-floor large office
building (one AHU per floor). Weather: TMY data for Chicago, IL.

## System

- 3 identical chillers. Each has one dedicated primary chilled-water pump and one dedicated condenser
  water pump (both constant speed).
- Primary chilled-water loops combine and feed a secondary loop with 2 identical variable-speed pumps.
  A bypass line balances primary and secondary flow.
- Condenser side: the 3 condenser loops combine and feed 3 identical cooling towers. A three-way valve
  lets condenser water bypass the towers (`TWV_CTRL`).
- Starting one chiller also starts one cooling tower, one condenser pump and one primary pump.

## Control sequence (important for rules and confounding)

- Chiller staging: number of chillers from the thermal load (state machine, 30-min wait).
- Secondary pump staging: state machine, 30-min wait. Pump speed keeps the secondary loop pressure
  difference at its set-point (35 psi in the text; logged in inH2O).
- Chilled-water supply set-point is **reset from outdoor dry-bulb temperature**: 42-52 degF as outdoor
  temperature moves between 60 and 80 degF (updated hourly).
- Condenser water set-point = **outdoor wet-bulb + 8 degF approach**, minimum 34 degF; tower fan speed
  tracks it. Tower leaving water is kept above 60 degF.
- Three-way valve keeps condenser water leaving the loop above 60 degF.

Consequence: many variables move with outdoor temperature by design. This is exactly the confounding
our improvement targets.

## Files

- 24 CSV files, about 430 MB each (about 10.3 GB unzipped). Store outside the repo if needed and set
  `DATA_DIR` in your `.env`.
- `ChillerPlant.csv`: fault-free baseline.
- 23 files, one fault scenario each: `ChillerPlant_<fault>_<severity>.csv`. **Each fault is active for the
  whole year.**
- `LBNL_FDD_Data_Sets_Chiller_Plant.pdf`: official documentation.
- `LBNL_FDD_Data_Sets_chiller_plant.ttl`: Brick-schema equipment model (useful for the association graph).
- `__MACOSX/`: junk from the zip, can be deleted.

## Size and sampling

- Sampling interval: 1 minute, starting 2018-01-01 (one simulated year, about 525,600 rows per file).
- 78 columns: `Datetime` + 77 variables.
- The first hour of each file was removed by LBNL (simulation start-up), so data starts at 01:00.
- Units: temperatures degF; flows GPM; power kW; `CWL_SEC_LOAD` W; pressures inH2O; control signals,
  speeds and valve position 0-1; status 0/1.
- Sensor-bias faults: the **logged value is the faulty value**. Note the bias is in degC
  (1 degC = 1.8 degF in the logged data).
- Very small values (e.g. 3.5e-18) are simulation noise and should be treated as 0.
- Preprocessing (src/preprocess.py, settings in config.yaml `preprocess:`): every file gets the same
  steps: frozen-sensor removal (60 min, weather excluded), no 3-sigma removal (simulated data has
  no sensor errors; on fault files it would delete the fault itself), 15-minute means, and only
  windows where at least one chiller is on. Output: `data/processed/<file>.parquet`.

## Plant operation (fault-free year)

- Chiller 1 is on almost all year; at winter load it delivers very little cooling, so COP is only
  computed when cooling >= 50 kW (`min_cool_kw`).
- Chiller 2 runs in summer only (about 770 h in the fault-free year).
- **Chiller 3 almost never runs** (about 38 h, on the hottest days), so after cleaning it has
  practically no data: its variables give no useful rules and should be left out of the graph.
- Cooling tower approach is only meaningful when the tower has flow and its fan is on;
  CT_APPROACH_i is blank otherwise (idle or bypass periods gave negative values).

## Fault scenarios

Each faulted case lasts one full year, so ground truth is per file: compare a fault file with the
fault-free file.

| Fault (documentation) | Files (intensity) | Affected variable | Paper category (draft) |
|---|---|---|---|
| Fault-free | `ChillerPlant.csv` | - | 0 normal |
| Chilled-water leaving temperature sensor bias, chiller 1 | `chiller_bias` -2, -1, +1, +2 degC | `CHL_SW_TEMP_1` | 2 operational |
| Condenser water leaving temperature sensor bias, cooling tower 1 | `coolingtower_bias` -2, -1, +1, +2 degC | `CT_SW_TEMP_1` | 2 operational |
| Differential pressure sensor bias, secondary loop | `secondary_chilled_water_pressure_bias` -20, -10, +10, +20 % | `CWL_SEC_DP` | 2 operational |
| Three-way valve leakage (condenser loop) | `bypass_leakage` 25, 50, 75 % | `TWV_CTRL` | 2 operational |
| Three-way valve stuck (condenser loop) | `bypass_stuck` 50, 75 % | `TWV_CTRL` | 2 operational |
| Cooling tower 1 heat-exchanger fouling | `coolingtower_fouling` 95, 80, 65 % of heat transfer coeff. | `CT_SW_TEMP_1`, approach, fan | 3 degradation |
| Inappropriate PI tuning, condenser supply temperature | `coolingtower_PI` | `CT_FAN_SPD_CTRL_*` | 2 operational |
| Chiller fouling (**not in the documentation**) | `chiller_fouling` 065, 095 | chiller heat transfer | 3 degradation |

Notes:
- The documentation lists 21 faulted cases; our download also has 2 `chiller_fouling` files that it
  does not describe. Use them only with care (or exclude them) and say so in the report.
- "Bypass" in the file names means the **condenser-loop three-way valve**, not the chilled-water bypass.
- Most faults affect unit 1 (chiller 1, cooling tower 1).
- No scenario corresponds to the paper's category 1 (design anomaly); our evaluation covers 3 of the 4
  categories.

## Variables (77)

Prefix meaning: `CHL` chiller, `CT` cooling tower, `CDWL` condenser water loop, `CWL_PRI` / `CWL_SEC`
primary / secondary chilled-water loop, `OA` outdoor air. Suffix `_1.._3` = unit number.
`SW` supply water, `RW` return water, `CD` condenser, `SPT` set-point, `STA` on/off status,
`CTRL` control signal, `POW` power, `SPD` speed, `DP` differential pressure.

| Group | Columns | Paper node type |
|---|---|---|
| Chillers (x3) | `CHL_POW_i`, `CHL_SW_TEMP_i`, `CHL_RW_TEMP_i`, `CHL_CW_FLOW_i`, `CHL_SWCD_TEMP_i`, `CHL_RWCD_TEMP_i`, `CHL_CD_FLOW_i` | sensor |
| | `CHL_COMP_SPD_CTRL_i`, `CHL_STA_i` | control |
| Cooling towers (x3) | `CT_POW_i`, `CT_FAN_SPD_i`, `CT_FLOW_i`, `CT_SW_TEMP_i`, `CT_RW_TEMP_i` | sensor |
| | `CT_FAN_SPD_CTRL_i`, `CT_STA_i`, `CT_SW_TEMPSPT` | control |
| Condenser water loop | `CDWL_CW_FLOW`, `CDWL_SW_TEMP`, `CDWL_RW_TEMP`, `CDWL_PM_POW_1..3` | sensor |
| Primary chilled-water loop | `CWL_PRI_CW_FLOW`, `CWL_PRI_SW_TEMP`, `CWL_PRI_RW_TEMP`, `CWL_PRI_PM_POW_1..3` | sensor |
| | `CWL_PRI_SW_TEMPSPT` | control |
| Secondary chilled-water loop | `CWL_SEC_CW_FLOW`, `CWL_SEC_SW_TEMP`, `CWL_SEC_RW_TEMP`, `CWL_SEC_DP`, `CWL_SEC_LOAD`, `CWL_SEC_PM_POW_1..2`, `CWL_SEC_PM_SPD_1..2` | sensor |
| | `CWL_SEC_DPSPT`, `CWL_SEC_PM_STA_1..2` | control |
| Condenser three-way valve | `TWV_CTRL` | control |
| Outdoor air | `OA_TEMP` (dry-bulb), `OA_TEMP_WB` (wet-bulb) | environment (**confounders for our improvement**) |

Notes: `CHL_CW_FLOW` is chilled-water flow; `CDWL_CW_FLOW` is condenser-water flow (both GPM).
`CHL_SWCD_TEMP` = condenser water leaving the chiller, `CHL_RWCD_TEMP` = entering.
The documentation spells the set-point `CWL_SEC_DPSPTS`; the CSV column is `CWL_SEC_DPSPT`.
`CWL_SEC_LOAD` (W) is a calculated load: secondary flow x supply/return temperature difference.

## Planned derived metrics (paper Eq. 1-5)

| Metric | Formula (imperial units) |
|---|---|
| Chilled-water delta T (per chiller) | `CHL_RW_TEMP_i - CHL_SW_TEMP_i` |
| Cooling capacity (per chiller, tons) | `CHL_CW_FLOW_i * deltaT / 24` (gpm, degF) |
| Chiller COP | cooling kW / `CHL_POW_i` (1 ton = 3.517 kW); only when `CHL_STA_i` = 1 |
| Plant total power | chillers + cooling towers + all pumps |
| Plant COP | (`CWL_SEC_LOAD` / 1000) / plant total power |
| Cooling tower approach | `CT_SW_TEMP_i - OA_TEMP_WB` |
| Condenser water delta T | `CHL_SWCD_TEMP_i - CHL_RWCD_TEMP_i` (leaving - entering) |
